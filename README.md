# recommend-book

世界の小説を整理し、読書履歴や好みに合う作品を探すためのデータ基盤です。10万作品を検索でき、資料のジャンルや審査済みの内容特徴がある作品から推薦候補を探せます。1万作品の詳細分類を反映しました。

## 現在使えるもの

2026年10月22日の実データ確認値です。ローカルの試作です。台帳・原資料・分類証跡の監査と、拡張後の推薦画面・実HTTP確認を完了し、[PR #28](https://github.com/ayutaz/recommend-book/pull/28)でmainへ反映済みです。Python 3.14の[Ubuntu・Windows CI](https://github.com/ayutaz/recommend-book/actions/runs/39696392433)も通過しました。

| 項目 | 状況 |
|---|---|
| 小説・ライトノベルの台帳 | 100,368作品。異なるWikidata作品IDを基準に収録 |
| 資料に基づく推薦対象 | 26,079作品。資料に記載されたジャンルを使用 |
| 詳細AI分類 | 10,000作品を分類・審査して反映 |

| 既存の詳細分類 | 872件を従来の試作データに保存。新台帳の件数には加算しません |
| 読書履歴 | 335評価を自動照合。新台帳への確実な接続は0件。従来の内容接続2件は別に維持 |

書名・別題・著者検索、ジャンル・年代・原言語の絞り込み、作品詳細、出典と推薦理由、既読除外、ページ分割に対応しています。好きな作品の複数指定と、テーマ・構造・主人公・雰囲気の重視/回避・重みの調整から候補を探せます。読書状態は保存され、状態不明の作品を未読とは扱いません。

資料のジャンルによる類似候補と、読書履歴に基づく個人推薦は区別します。独立した正解データによる分類精度、確信度の校正、本人向け推薦の改善は未評価です。翻訳・版の対応や独立した名寄せ精度も未検証です。

詳細分類では、テーマ・物語構造・主人公・雰囲気などの根拠付き特徴を使います。根拠がない項目は不明とし、原作本文の裏付けがない文体は推定しません。

推薦の最終HTTPは、テーマ重み0で約20.4秒、重み2で約31.0秒でした。各1回の観測で、待ち時間は残ります。[10万作品・1万分類の完了結果](docs/scale-catalogue-v3.md)に、6軸の内訳・利用量・確認範囲をまとめています。[3万作品・5,000分類の結果](docs/scale-catalogue-v2.md)は前段階の記録です。

## ローカルで開く

Python 3.14と[uv](https://docs.astral.sh/uv/)を使います。この環境の生成済み台帳は次のコマンドで開けます。

```powershell
uv sync --locked
uv run python scripts/serve_scale_catalogue_v1.py --database data/autonomous-next-v3/scale-v1/catalogue.sqlite --port 8766
```

ブラウザで [小説の本棚](http://127.0.0.1:8766/) を開きます。

取得データ・DB・個人履歴はGit対象外の `data/` に保存します。リポジトリを取得するだけでは推薦用データは揃いません。従来の試作画面は `data/autonomous-next-v3/database/phase17-world-delivery-v1/index.html` にあります。

開発用の検証は `uv run --locked pytest -q` で実行できます。CIと実データ・画面の確認は区別します。

## ここから進めること

実行中の計画は[v20](docs/autonomous-next-phase-plan-v20.md)、現在地と次の手順は[2万分類への実行状況](docs/scale-classification-v4.md)にまとめています。10月22日19:09時点で、作業ブランチの詳細分類は10,249作品です。取得済み資料から入力を準備し、累計2万作品への追加分類を進めています。読書状態の再起動後の保持と、実ブラウザーでのJSONファイル保存も確認しました。2万分類と最終CIは未完了です。

1. 日本語作品やジャンル・年代別の不足と保存資料を確認し、新規作品だけを分類して累計2万作品を目指します。使える単位で順次反映します。
2. 分類拡張と並行して推薦の待ち時間を改善し、履歴の保存・削除・持ち出しを整えます。
3. 新しい対応根拠が得られた既存評価だけを照合し、用途別の利用条件と無料運用範囲を確認してToC候補をまとめます。

既存履歴と確実に結び付く範囲で評価し、追加の試読・採点・履歴入力は依頼しません。

データ購入・外部委託・有料APIへの切替は行わず、無料公開資料と既存のCodex CLIを使います。データのAI入力・表示・再配布・商用利用条件は資料と用途ごとに管理します。
