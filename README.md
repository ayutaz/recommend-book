# recommend-book

世界の小説を整理し、読書履歴や好みに合う作品を探すためのデータ基盤です。10万作品を検索でき、資料のジャンルや審査済みの内容特徴がある作品から推薦候補を探せます。詳細分類を累計1万作品へ増やしています。

## 現在使えるもの

2026年10月21日、10万作品到達時点の確認値です。ローカルの試作で、今回の最終監査・拡張後の推薦確認・CIは残っています。

| 項目 | 状況 |
|---|---|
| 小説・ライトノベルの台帳 | 100,368作品。異なるWikidata作品IDを基準に収録 |
| 資料に基づく推薦対象 | 26,079作品。資料に記載されたジャンルを使用 |
| 詳細AI分類 | 6,578作品を分類・審査して反映。累計1万作品へ拡張中 |
| 既存の詳細分類 | 872件を従来の試作データに保存。新台帳の件数には加算しません |
| 読書履歴 | 335評価を自動照合。新台帳への確実な接続は0件。従来の内容接続2件は別に維持 |

書名・別題・著者検索、ジャンル・年代・原言語の絞り込み、作品詳細、出典と推薦理由、既読除外、ページ分割に対応しています。好きな作品の複数指定と、テーマ・構造・主人公・雰囲気の重視/回避・重みの調整から候補を探せます。読書状態は保存され、状態不明の作品を未読とは扱いません。

資料のジャンルによる類似候補と、読書履歴に基づく個人推薦は区別します。独立した正解データによる分類精度、確信度の校正、本人向け推薦の改善は未評価です。翻訳・版の対応や独立した名寄せ精度も未検証です。

詳細分類では、テーマ・物語構造・主人公・雰囲気などの根拠付き特徴を使います。根拠がない項目は不明とし、原作本文の裏付けがない文体は推定しません。

[現在の実施状況](docs/scale-catalogue-v3.md)に、10万作品到達の確認結果と推薦・分類の残作業を記録しています。[3万作品・5,000分類の完了結果](docs/scale-catalogue-v2.md)も参照できます。

## ローカルで開く

Python 3.14と[uv](https://docs.astral.sh/uv/)を使います。この環境の生成済み台帳は次のコマンドで開けます。

```powershell
uv sync --locked
uv run python scripts/serve_scale_catalogue_v1.py --database data/autonomous-next-v3/scale-v1/catalogue.sqlite --port 8766
```

ブラウザで [小説の本棚](http://127.0.0.1:8766/) を開きます。

取得データ・DB・個人履歴はGit対象外の `data/` に保存します。リポジトリを取得するだけでは推薦用データは揃いません。従来の試作画面は `data/autonomous-next-v3/database/phase17-world-delivery-v1/index.html` にあります。

開発用の検証は `uv run --locked pytest -q` で実行できます。CIと実データ・画面の確認は区別します。

## ここから進めること

3万作品の拡張と5,000作品の分類はCI・main反映まで完了しました。現在は以下を並行して進めています。

1. 書誌10万作品への取得・反映は件数目標を達成しました。原資料・用途条件・重複・既存データ保持の最終確認を行います。
2. 好みを指定する推薦を、拡張後の実データ・画面・性能で確認します。既存履歴と結び付けられる範囲で評価し、追加の試読・採点・履歴入力は依頼しません。
3. 利用条件を満たす内容資料のある未処理作品から、詳細分類を累計1万作品へ増やします。

最終確認後に結果とREADMEを確定し、Ubuntu・WindowsのPython 3.14 CI、mainへの反映まで進めます。

データ購入・外部委託・有料APIへの切替は行わず、無料公開資料と既存のCodex CLIを使います。データのAI入力・表示・再配布・商用利用条件は資料と用途ごとに管理します。
