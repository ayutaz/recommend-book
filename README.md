# recommend-book

世界の小説を整理し、読書履歴や好みに合う作品を推薦するためのデータ基盤です。古典から現代小説・ライトノベルまでを対象に、まず1,000〜3,000作品で試作し、将来は10万作品以上への拡張を目指します。

## できること

- Open Library・国立国会図書館・Wikidataなどの書誌情報を取り込み、作品・翻訳・刊行版を区別して管理します。
- LLMでジャンル、テーマ、物語構造、主人公、文体、雰囲気を分類し、判定の根拠と信頼度を保存します。根拠が足りない項目は「不明」として扱います。
- 読書履歴を使って候補に順位を付け、推薦理由を表示します。既読と確認できた作品は除外します。
- データごとの利用条件を記録し、AI入力・表示・再配布などに使える範囲を管理します。

分類精度・信頼度の校正・本人向け推薦の改善は、まだ検証できていません。翻訳や版の対応も一部に限られます。読書状態が不明な作品を「未読」とは扱いません。商用利用は資料や用途ごとに確認が必要です。

実装は[PR #2](https://github.com/ayutaz/recommend-book/pull/2)で`main`へ統合済みです。その実装版の[Windows・UbuntuのCI](https://github.com/ayutaz/recommend-book/actions/runs/38701147898)は成功しています。件数や検証範囲の詳細は[実生成・検証報告](docs/autonomous-next-delivery-report-v3.md)にまとめています。

## 開発・ローカルでの確認

Python 3.12以上と[uv](https://docs.astral.sh/uv/)を使用します。

```powershell
uv sync --locked
uv run recommend-book --help
uv run pytest -q
```

取得データ・DB・評価資料は`data/`にローカル保存しており、Gitには含めていません。リポジトリを取得するだけでは推薦用データは揃いません。

生成済みデータがある環境では、次のファイルをブラウザで開くと推薦画面を確認できます。

```text
data/autonomous-next-v3/database/phase3-personal-poc-with-declared-genres-v2/index.html
```

## 次に進めること

1. 更新処理で未確認の、内容特徴の失効・中断後の再開・撤回後の表示を少数例で確認する。
2. 読書履歴と内容特徴の接続を改善し、固定した条件で推薦方式を比較する。
3. 保存資料とCodexで分類・名寄せの未解決事項を診断し、修正や保留をDBと推薦へ反映する。

その後、確認できた品質の範囲と処理量を見ながら1万→3万→10万作品へ拡張します。

追加の試読・採点・正解データ作成を利用者へ依頼しない方針です。

追加費用をかけず、既存データ・利用条件を満たす無料公開資料・Codexだけで進めます。外部委託やデータ購入は行いません。Codexによる評価と、独立した人手による精度検証は区別します。
