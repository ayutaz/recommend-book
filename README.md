# recommend-book

世界の小説を整理し、読書履歴や好みに合う作品を探すためのデータ基盤です。10万作品を検索でき、資料のジャンルや審査済みの内容特徴がある作品から推薦候補を探せます。作業ブランチでは2万作品の詳細分類と最終監査を完了しました。

## 現在使えるもの

世界小説の以下の値は2026年10月24日の実DBで確認しました。ローカルの試作で、最終監査・利用量集計・推薦画面・実HTTPの確認を完了しています。2万分類版の[CI](https://github.com/ayutaz/recommend-book/actions/runs/40093412432)はUbuntu・Windowsとも成功し、[PR #30](https://github.com/ayutaz/recommend-book/pull/30)でmainへ反映済みです。追加中のライトノベル対応は作業ブランチの[PR #31](https://github.com/ayutaz/recommend-book/pull/31)にあります。

| 項目 | 状況 |
|---|---|
| 小説・ライトノベルの台帳 | 100,370作品を検索可能。異なるWikidata作品IDを基準に収録 |
| 資料に基づく推薦対象 | 26,081作品。資料に記載されたジャンルを使用 |
| 詳細AI分類 | 20,000作品を分類・審査して採用。既存1万作品を保持 |
| 表示可能な詳細特徴 | 18,456作品。根拠不足・保留の特徴は表示しません |
| 既存の詳細分類 | 872件を従来の試作データに保存。新台帳の件数には加算しません |
| 読書履歴 | 335評価を自動照合。新台帳への確実な接続は0件。従来の内容接続2件は別に維持 |

書名・別題・著者検索、ジャンル・年代・原言語の絞り込み、作品詳細、出典と推薦理由、既読除外、ページ分割に対応しています。好きな作品の複数指定と、テーマ・構造・主人公・雰囲気の重視/回避・重みの調整から候補を探せます。読書状態は保存され、状態不明の作品を未読とは扱いません。

資料のジャンルによる類似候補と、読書履歴に基づく個人推薦は区別します。独立した正解データによる分類精度、確信度の校正、本人向け推薦の改善は未評価です。翻訳・版の対応や独立した名寄せ精度も未検証です。

日本のライトノベル用に、シリーズ・各巻・版を分けた検索と推薦を追加しました。「魔法科高校の劣等生」はシリーズとして検索し、好きな作品に指定できます。ライトノベル検索では、句読点や巻数・副題の並びが異なる書名と、正式な出版社対応で確認した完全題にも対応しています。出版社の掲載グループや独立した掲載書誌も検索でき、物語シリーズや確認済みの版と区別して表示します。NDL未接続などの紙・電子専売書誌も、ローカルで出版社の掲載書誌として探せます。シリーズ数と内容特徴の分類は初期目標を満たし、現在は出版社・レーベル別の収録漏れと対応書誌を補っています。ほぼ網羅できた段階ではありません。件数と確認時点は[追加状況と残作業](docs/light-novels-progress-v1.md)にまとめています。

詳細分類では、テーマ・物語構造・主人公・雰囲気などの根拠付き特徴を使います。根拠がない項目は不明とし、原作本文の裏付けがない文体は推定しません。

2万分類での推薦HTTPは、テーマ重み0で約42.0秒、重み2で約36.7秒でした。各1回の観測で、待ち時間は残ります。[10万作品・2万分類の検証結果](docs/scale-catalogue-v4.md)に、6軸の内訳・利用量・確認範囲をまとめています。[1万分類の結果](docs/scale-catalogue-v3.md)は前段階の記録です。

## ローカルで開く

Python 3.14と[uv](https://docs.astral.sh/uv/)を使います。この環境の生成済み台帳は次のコマンドで開けます。

```powershell
uv sync --locked
uv run --locked python scripts/serve_scale_catalogue_v1.py --database data/autonomous-next-v3/scale-v1/catalogue.sqlite --light-novels-database data/light-novels-v1/catalogue.sqlite --port 8769
```

ブラウザで [小説の本棚](http://127.0.0.1:8769/) を開きます。書名検索はすぐに使えます。収録状況や詳しい絞込み候補は「収録状況と詳しい絞込みを表示」から読み込みます。「対象」で「日本のライトノベル」、「種別」で「シリーズ・作品グループ」を選ぶとシリーズなどの単位で探せます。ライトノベルDBを用意していない環境では、`--light-novels-database`を省略して世界小説だけを開けます。

取得データ・DB・個人履歴はGit対象外の `data/` に保存します。リポジトリを取得するだけでは推薦用データは揃いません。従来の試作画面は `data/autonomous-next-v3/database/phase17-world-delivery-v1/index.html` にあります。

開発用の検証は `uv run --locked pytest -q` で実行できます。CIと実データ・画面の確認は区別します。

## ここから進めること

最新の計画は[v25：日本のライトノベルを広く収録する](docs/autonomous-next-phase-plan-v25.md)、現在地は[ライトノベル対応の進捗](docs/light-novels-progress-v1.md)にまとめています。[2万分類の到達状況](docs/scale-classification-v4.md)は前段階の記録です。新たな不具合や変更がなければ同じ分類・監査・画面確認を繰り返しません。

1. 出版社のシリーズ一覧とNDL作成の書誌を照合し、未収録のシリーズを補います。
2. 確認済みのシリーズと内容特徴を保持し、追加書誌をシリーズ検索・推薦へ接続します。旧作・女性向け・電子専売の不足も補います。
3. レーベル・年代ごとの収録と未解決の不足を報告し、日本のライトノベルの利用を保ちながら世界小説の3万・5万・10万作品への拡張へ進みます。

ライトノベル対応は[PR #31](https://github.com/ayutaz/recommend-book/pull/31)で進めています。現在はdraftです。一般公開・商用提供は用途条件と公開構成が成立した段階で扱います。

既存履歴と確実に結び付く範囲で評価し、追加の試読・採点・履歴入力は依頼しません。

データ購入・外部委託・有料APIへの切替は行わず、無料公開資料と既存のCodex CLIを使います。データのAI入力・表示・再配布・商用利用条件は資料と用途ごとに管理します。
