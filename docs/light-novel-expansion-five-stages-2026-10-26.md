# ライトノベル追加：5段階の実行記録

ユーザー指定の計画は、①未接続の仕分け、②検索への追加、③作品・シリーズ・版の整理、④不足資料の新規取得、⑤内容分類と推薦への接続。5までを実行対象とし、掲載参照の追加だけで完了にはしない。

開始時点は100,719 entry、版候補87,278、物語シリーズ2,197、出版社掲載参照9,969、内容特徴572シリーズ、所属関係5,031。DBの全entry ID・kind・SHAと各tableの行数・内容SHAを読み取り専用で固定した。版候補のうち82,247は所属関係が未登録だが、新作数やラノベ確定数へ換算しない。

保存済み17 source bundleと742件の分類予約を照合し、未試行のあらすじ入力は0だった。日本の小説カテゴリとして採用済みでも原言語が不明な14シリーズは、追加取得した記事を分類器の既存条件が拒否した。日本語原著と補わず、分類呼出し0で保留する。

未試行かつ日本語原著を確認済みの20シリーズについて、新たにロシア語記事の資料準備を実行した。既存のロシア語あらすじ抽出規則をCLIでも選択可能にし、同じ出典確認・段落検査・帰属の規則を使用する。10シリーズにあらすじがあり、分類10呼出し・別審査2呼出しで採用gateを通過、失敗・未着手0。DBには10シリーズ分の特徴exportを追加し、内容特徴を得たのは8シリーズ（572→580）。残2シリーズを内容分類済みへ換算しない。独立精度・信頼度校正・本人向け改善は未評価。

新しい出版社取得枠として[DREノベルス公式年別一覧](https://drecom-media.jp/drenovels/product)を追加した。robotsを保存し、2022・2023・2024・2026年の95掲載カードを確認した。2025年の1回の取得はHTTP 500で保留し、同URLは再送していない。発売予定も含む部分取得であり、全歴史の取得完了ではない。

現在DBとの1回の書誌metadata照合では95参照のうち完全題の候補13、同ISBNの候補91。これは同一版・作品の証明ではない。完全題の候補がない82参照を独立した出版社掲載書誌として追加した（100,719→100,801 entry、掲載参照9,969→10,051）。そのうちISBN候補もないのは4参照。82新作・82新シリーズとは報告しない。全旧entryと、所属・版確認・書誌対応・読書状態・失敗台帳を保持した。

## シリーズ接続・推薦の追加確認

DREの公式商品詳細8頁から、各商品の「シリーズ紹介」リンクと同じURLを持つ明示されたシリーズ名、主書誌の著者役割を再現した。まず既存のNDLシリーズ採用処理へ8参照を渡したが、WD重複候補4・適格NDL anchorなし4で採用0だった。重複シリーズは作成していない。

追加の対応では、Wikidataの非deprecated P856が公式のシリーズURLと完全一致することを、保存された同じentity rawから確認する。公式シリーズの関係、NDL自身の日本語小説書誌・完全な主題名・巻次・出版者・著者役割と典拠を検査する。P856がなければ、従来型の独立した著者典拠対応とWDの出版者・著者の一致を要求する。氏名だけで人物同一性を宣言しない。

最初の31版の限定確認は接続0だった。原因の一つはNDLの実叢書欄が英字の `DRE NOVELS` だったこと。公式の当該小説シリーズ既刊一覧にある同ISBN・同巻次・同著者のカードを使い、その版だけの叢書表記の根拠として再現した。グローバルな別名辞書は作成していない。新しい条件を満たした『ブレイド＆バスタード』2〜6巻の5版を既存WDシリーズへ接続し、他26版は保留、旧接続の置換0・新シリーズ0。所属関係は5,031→5,036となった。1巻は巻次が明示されないため自動補完していない。

推薦では、候補にならない版を全件再生する処理が大きなメモリを使ったため、全シリーズ・作品と、好み指定または既読の版、その親だけを認証するよう変更した。元の推薦結果との比較、未接続の好み指定、既読の接続巻による親除外をfixtureで検証する。新たに分類した『サクラダリセット』を好み入力にして5件の推薦を返すことを実DBで確認した（228.101秒、単発観測）。実測はまだ遅く、速度保証・SLO達成とはしない。中間の全件処理はDREの開発中フィールド不一致で失敗しており、成功した比較の基準には使わない。

途中実装のローカル全試験は5,282 pass・失敗0（907.46秒）。後続の推薦候補選択・シリーズ接続の変更を含む最終全体確認の代用にはしない。

同じ版限定の根拠を既存のNDLシリーズ採用処理へ接続し、新しく3物語シリーズを採用した。『汝、暗君を愛せよ』『勇者のオマケだったので、異世界を自由に旅することにした』『婚約者が浮気相手と駆け落ちしました。王子殿下に溺愛されて幸せなので、今さら戻りたいと言われても困ります。』。各巻6版も接続した。WDとの重複候補4と基準書誌不足1は引き続き保留した。

## 最初の1,000版の処理と公式特設ページによる接続

87,278版を出版社・叢書の実表記ごとに2,744群へ仕分けし、既存所属、既存シリーズ題名候補なし、metadata不足、所属根拠待ちを分けた。同ISBNの複数書誌候補125は独立した注意項目であり、重複削除しない。電撃321・HJ271・オーバーラップ232・富士見176の計1,000版をIDとSHAで固定した。既存の典拠照合はこの対象で新規接続0。既存NDL親シリーズの巻再照合も新規0だった。後から到着した巻を明示的に再照合できる `refresh_memberships` を追加したが、根拠条件は維持した。

保存済みWikidataの公式URLから小説専用の公式特設ページを有限取得した。robotsを確認できたKADOKAWA特設5頁を保存。別ホストのrobotsが転送された5候補は未取得として保留し、禁止と断定も迂回もしていない。公式の小説一覧コンテナ内にある商品リンクだけを使い、別枠の短編集・漫画・ナビゲーションを所属根拠にしない。出版社本文の分類入力は0。

公式商品書誌との既存の独立照合、NDL自身の日本語小説書誌・明示巻次・主題名、Wikidataの日本語原著と公式URL一致を再検証し、最初の1,000版のうち30版を接続した。内訳は『ハイスクールD×D』10、『錆喰いビスコ』9、『王様のプロポーズ』5、『経験済みなキミと、経験ゼロなオレが、お付き合いする話。』6。最後の6版は明示された「その2」〜「その7」を巻次として読む。DXや上・下を数値へ推定変換しない。限定照合46版の残16版は商品確認不足11、DX別枠3、上・下2で保留。保存資料の改変・期限切れでは所属を表示せず、独立書誌は保持する。

今回の新規所属はDRE11と特設30の計41、所属総数5,072。新しい版行は0、entry総数100,804、物語シリーズ2,200、掲載参照10,051、内容特徴580シリーズ。開始時点の全旧entryと各table内容SHAを照合し、全旧行の保持を確認した。証跡は `preservation-audit-memberships41.json`。最初の1,000版は接続30・保留970として全IDを記録し、台帳は `publisher-imprint-connection-matrix-memberships41.json` とCSVへ差分更新した。その他の候補まで整理完了とはしない。

先行するc3ecd21のCI run 40247658495は両OS成功をartifactで確認した。Ubuntuは5,296 pass・7 skip、Windowsは5,297 pass・6 skip、双方失敗0、merge checkoutの全treeが当該headと一致した。後続の特設ページ対応を含む最終headのCIは別に必要。
