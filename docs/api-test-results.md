## 追加調査（2026-03-01 第2回）

想定と異なった3つのAPI（openBD、NDLサーチ、Google Books）を深掘り調査した結果。

### openBD: 500件ランダムサンプル統計

coverageから日本のISBN（978-4-xxx）を500件ランダム抽出して統計を取った。

| フィールド | 存在率 | 備考 |
|-----------|--------|------|
| CollateralDetail.TextContent（テキスト情報） | **17.0%** | 5冊に1冊程度 |
| summary.cover（書影URL） | **6.6%** | 約15冊に1冊 |
| hanmoto.reviews（書評情報） | **4.4%** | メタ情報のみ（本文なし） |
| hanmoto.kaisetsu105w（105字解説） | **2.6%** | 入っている場合は実用的 |
| hanmoto.obinaiyou（帯の内容） | **0.2%** | 極めて稀 |
| hanmoto.lanove（ラノベフラグ） | **0.0%** | 事実上未使用 |

#### TextContentのTextType別の意味

| TextType | 意味 | レコメンド活用 |
|----------|------|-------------|
| `"02"` | 短い説明（キャッチコピー的） | 補助的に使える |
| `"03"` | **長い説明（あらすじに最も近い）** | 最も有用 |
| `"04"` | 目次 | ジャンル推定の補助に |

#### 充実度の傾向

- **中小出版社**（えにし書房、ほんの木、筑摩書房等）の方がデータが豊富
- **大手出版社**（講談社、早川書房、集英社等）ほどデータが空
- `lanove`フラグは500件中0件。ラノベ判別にはレーベル名（電撃文庫等）を使うべき

#### 結論

openBDは「ISBNから基本書誌情報（タイトル、著者、出版社、価格）を確認する補助ソース」に限定。あらすじ取得率17%はメインソースとしては不十分。

### NDLサーチ: 図書限定・件名検索の方法

#### 図書のみに絞り込む方法

**SRU APIの `mediatype="books"` が最善。**

| mediatype値 | 意味 |
|-------------|------|
| `books` | 図書 |
| `periodicals` | 逐次刊行物 |
| `articles` | 記事・論文 |
| `electronic` | 電子資料 |

```bash
# SRU: 図書限定でSAOを検索（495件に絞り込み成功）
curl "https://ndlsearch.ndl.go.jp/api/sru?operation=searchRetrieve&query=title%3D%22ソードアート・オンライン%22%20AND%20mediatype%3D%22books%22&recordSchema=dcndl&maximumRecords=5"
```

注意: OpenSearch APIでは `mediatype` パラメータは機能しない。`dpid=iss-ndl-opac` で代替可能だがゲーム等も混在する。

#### 件名（subject）によるジャンル検索

SRU APIの `subject` インデックスで「推理小説」等のNDL件名標目を検索可能。

```bash
curl "https://ndlsearch.ndl.go.jp/api/sru?operation=searchRetrieve&query=subject%3D%22推理小説%22%20AND%20mediatype%3D%22books%22&recordSchema=dcndl&maximumRecords=5"
```

ただし注意: NDLの件名は「推理小説について論じた本」に付くことが多く、**推理小説作品そのものには付かないケースがある**。

#### dcndlスキーマの追加フィールド

| フィールド | 内容 |
|-----------|------|
| `dcterms:subject` (NDL件名標目) | 「推理小説」等のジャンル件名（URI付き） |
| `dcterms:subject` (NDC) | `913.6` 等のNDC分類 |
| `dcterms:audience` | 対象読者（一般/児童等） |
| `foaf:Agent` (URI) | 著者の典拠URI |
| `dcterms:isPartOf` | シリーズ名（電撃文庫等） |
| `dcterms:abstract` | あらすじ（**サピエ図書館由来データのみ**） |

#### あらすじについて

- NDL本体のレコードには**あらすじは含まれない**
- **サピエ図書館**（視覚障害者向け）由来のデータには`dcterms:abstract`にしっかりしたあらすじが入る場合がある
- ただし網羅性は低い

### Google Books API: 全リクエスト429エラー

APIキーなし・sleep・User-Agent変更等あらゆる回避策を試したが、全リクエストが**429 (Too Many Requests)** で失敗。

- 原因: APIキーなし時の共有プロジェクト(`project_number:624717413613`)の日次クォータ枯渇
- **対処法: GCPプロジェクトでAPIキーを発行すれば専用クォータ（1,000リクエスト/日）が割り当てられる**
- 本プロジェクトでの優先度は低いため、必要になった時点でAPIキー取得を推奨
