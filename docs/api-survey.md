## 1. AniList API (GraphQL)

### 概要
アニメ・マンガ・ライトノベルを扱う大規模データベース（2026-03-01調査時の説明）。ライトノベルは MANGA タイプの NOVEL フォーマットとして格納されていると記録した。

### エンドポイント・仕様
- **URL**: `https://graphql.anilist.co`
- **方式**: GraphQL
- **認証**: 不要（公開データの読み取りのみ）。OAuth2 で認証すると上位のレートリミットとユーザーデータアクセスが可能
- **料金**: 調査時は無料と記録（現行条件は要確認）

### 取得できるデータ
- タイトル（日本語・英語・ローマ字）
- あらすじ（description）
- ジャンル（Action, Adventure, Comedy, Drama, Fantasy, Horror, Mystery, Romance, Sci-Fi 等）
- タグ（数百種類: Isekai, Time Travel, Revenge, Overpowered MC 等、ユーザー投票ベース）
- 評価スコア（平均スコア、人気度）
- スタッフ・キャラクター情報
- メディアリレーション（原作 → アニメ化、コミカライズ等の関連付き）
- 放送・発売情報
- スタジオ情報

### レートリミット
- **90リクエスト/分**（認証なし）
- 超過時は1分間のタイムアウト
- レスポンスヘッダに `X-RateLimit-Limit`, `X-RateLimit-Remaining` が含まれる
- バーストリミッターあり（短時間の大量リクエスト防止）

### 活用可能性: ★★★★★
- ラノベ原作 → アニメ化のメディアミックス情報を取得できる
- タグシステムが非常に充実しており、レコメンドのフィーチャーとして活用可能
- 「異世界転生」「チート」「俺TUEEE」等のなろう系タグも多数存在
- GraphQL なので必要なフィールドだけ取得でき効率的
- 日本語タイトルで検索可能

### 公式ドキュメント
- https://docs.anilist.co/
- https://anilist.co/graphiql（インタラクティブエクスプローラ）

## 2. Jikan API (非公式 MyAnimeList API)

### 概要
MyAnimeList（MAL）のデータを提供する非公式 REST API。MAL 自体は公式 API v2 を提供しているが、Jikan の方がアクセスしやすい。

### エンドポイント・仕様
- **URL**: `https://api.jikan.moe/v4/`
- **方式**: REST API (JSON)
- **認証**: 不要（API キー不要）
- **料金**: 調査時は無料・オープンソースと記録（現行条件は要確認）

### 主要エンドポイント
- `GET /manga/{id}` - マンガ詳細
- `GET /manga` - マンガ検索
- `GET /anime/{id}` - アニメ詳細
- `GET /characters/{id}` - キャラクター情報
- `GET /top/manga` - マンガランキング

### 取得できるデータ
- タイトル（日本語・英語）
- あらすじ（synopsis）
- ジャンル、テーマ、デモグラフィック
- スコア（MAL スコア）、ランキング、人気度
- 出版状況、巻数、話数
- 著者・スタジオ情報
- リレーション（原作 ↔ メディアミックス）

### レートリミット
- **60リクエスト/分**（v4）
- 秒間2リクエストまで
- セルフホスト可能（制限なし）

### 活用可能性: ★★★★☆
- MAL は大規模なアニメ・マンガデータベースであり、ユーザースコアを補助特徴として利用できる可能性がある
- ラノベのカバー率は AniList に比べてやや低い
- セルフホスト可能なため、大量データ取得時に有利
- REST なので GraphQL より扱いやすい場合もある

### 公式ドキュメント
- https://docs.api.jikan.moe/
- https://jikan.moe/

### MyAnimeList 公式 API v2 について
- URL: `https://api.myanimelist.net/v2/`
- OAuth2 認証が必要
- レートリミット: 公式には非公開（実質 ~1リクエスト/秒推奨）
- Jikan よりデータが正確だが、アクセスのハードルが高い

## 3. メディア芸術データベース（MADB）- 文化庁 / 国立アートリサーチセンター

### 概要
文化庁が構築し、2024年1月に正式公開されたと当時記録した。マンガ・アニメーション・ゲーム・メディアアートの作品情報を Linked Open Data として提供する（運営主体や提供範囲は要再確認）。

### エンドポイント・仕様
- **SPARQL エンドポイント**: `https://mediaarts-db.artmuseums.go.jp/sparql`
- **方式**: SPARQL (Linked Open Data / RDF)
- **認証**: 不要
- **料金**: 調査時は無料と記録（現行条件は要確認）
- **データセットダウンロード**: 当時の資料では全件一括取得可能と記載。現在の提供条件を要確認

### 取得できるデータ
- マンガ作品情報（タイトル、作者、掲載誌、巻号）
- アニメーション作品情報（タイトル、制作会社、放送期間）
- ゲーム作品情報
- メディアアート情報
- 作品間のリレーション（原作 → アニメ化等）
- 所蔵情報

### レートリミット
- 明確な公式制限なし（常識的な範囲で利用）

### 活用可能性: ★★★☆☆
- メディアミックス情報（原作小説 → アニメ化 → コミカライズ）を参照できる候補（収録範囲は要確認）
- SPARQL なので柔軟なクエリが可能だが、学習コストがある
- Wikidata とのフェデレーテッドクエリに対応
- エンタメ特有のタグ・ジャンル情報は乏しい
- あらすじ・評価情報はない

### 公式サイト
- https://mediaarts-db.artmuseums.go.jp/
- https://mediag.bunka.go.jp/madb_lab/（MADB Lab）
- https://mediag.bunka.go.jp/madb_lab/lod/howto/（利用方法）

## 4. Amazon Product Advertising API (PA-API 5.0) → Creators API

### 概要
Amazon の商品データを取得するための公式 API。書籍のレビュー数・評価・カテゴリ情報を取得可能。ただし、2026-03-01の記録では **2026年4月30日にPA-API廃止予定** とされ、後継の **Creators API** への移行が必要と整理していた。現在の提供状況・移行条件は一次資料で再確認する。

### エンドポイント・仕様
- **PA-API 5.0**: `https://webservices.amazon.co.jp/paapi5/` （当時は2026年4月末廃止予定との記録）
- **Creators API**: `https://affiliate.amazon.co.jp/creatorsapi`（当時の後継候補）
- **方式**: REST API
- **認証**: Amazon アソシエイトアカウント + アクセスキー/シークレットキー
- **料金**: 調査時は無料だが売上要件ありと記録（現行条件は要確認）

### 利用条件（重要）
- Amazon アソシエイトプログラムへの参加・承認が必要
- **過去30日以内に10件以上の適格な売上** が必要（2025年11月改定）
- 初期は1日8,640リクエスト、売上に応じて最大864,000リクエスト/日まで増加
- 売上 $0.05（約5円）ごとに1リクエスト追加

### 取得できるデータ
- 商品情報（タイトル、著者、出版社、ISBN/ASIN）
- 価格情報
- カテゴリ・ブラウズノード
- 商品画像
- レビュー数・星評価（一部制限あり）
- 関連商品
- プライム対象かどうか

### 活用可能性: ★★★☆☆
- 書籍の実売データ・評価情報が取得できる点は大きい
- ただし売上要件が厳しく、個人開発や初期段階では利用困難
- レビューの詳細テキストは取得不可（数と星のみ）
- PA-API の廃止・Creators API の移行条件は、調査後に変わっている可能性があるため現在の一次資料を確認する

### 公式ドキュメント
- https://affiliate.amazon.co.jp/help/node/topic/GMEDADBTCJ9KD8DQ
- https://affiliate.amazon.co.jp/creatorsapi

## 5. ISBNdb API

### 概要
2001年設立の大規模な ISBN 書籍データベース。1億800万タイトル以上という件数は当時の資料に基づく記録であり、現在の件数は要確認。

### エンドポイント・仕様
- **URL**: `https://api2.isbndb.com/`
- **方式**: REST API (JSON)
- **認証**: API キー必要（有料プランで発行）
- **料金**: 有料のみ
  - Basic: $14.95/月（1リクエスト/秒）
  - Premium: $29.95/月（3リクエスト/秒）
  - Pro: $74.95/月（リアルタイム価格情報付き）

### 主要エンドポイント
- `GET /book/{isbn}` - ISBN で書籍検索
- `GET /books/{query}` - キーワード検索
- `GET /author/{name}` - 著者検索
- `GET /publisher/{name}` - 出版社検索
- バルク検索（1回で最大1,000件）

### 取得できるデータ（最大19項目）
- ISBN10, ISBN13
- タイトル、著者、出版社、出版日
- ページ数、装丁（ハードカバー/ペーパーバック等）
- あらすじ（synopsis）
- 表紙画像 URL
- 言語、版、フォーマット
- 主題（subject）
- 重量、寸法
- 定価

### レートリミット
- Basic: 1リクエスト/秒
- Premium: 3リクエスト/秒

### 活用可能性: ★★☆☆☆
- 日本語書籍のカバー率は不明（英語圏中心）
- 有料のみで無料プランなし
- エンタメ特有のタグ・ジャンル情報は乏しい
- ISBN ベースの基本書誌情報取得には使えるが、openBD や NDL の方が日本語書籍には適している

### 公式ドキュメント
- https://isbndb.com/isbndb-api-documentation-v2

## 6. MangaDex API

### 概要
広告なしのマンガリーダープラットフォーム。マンガのメタデータ・タグ情報が充実しており、スキャンレーション（翻訳）グループの情報も含む。

### エンドポイント・仕様
- **URL**: `https://api.mangadex.org/`
- **方式**: REST API (JSON)
- **認証**: OAuth2（多くの GET エンドポイントは認証不要）
- **料金**: 調査時は無料と記録（現行条件は要確認）

### 主要エンドポイント
- `GET /manga` - マンガ検索（タグフィルタリング対応）
- `GET /manga/{id}` - マンガ詳細
- `GET /manga/tag` - タグ一覧
- `GET /chapter` - チャプター検索

### 取得できるデータ
- タイトル（多言語対応、日本語含む）
- あらすじ（description、多言語）
- タグ（ジャンル、テーマ、フォーマットなど詳細なタグシステム）
  - ジャンル: Action, Adventure, Comedy, Drama, Fantasy, Horror, Mystery, Romance, Sci-Fi 等
  - テーマ: Isekai, Reincarnation, Villainess, Video Games 等
- デモグラフィック（少年、少女、青年、女性向け）
- 出版状態、年
- 原作リンク
- 著者・アーティスト
- コンテンツレーティング

### タグフィルタリング
- `includedTags[]` / `excludedTags[]` でタグベースのフィルタリングが可能
- AND/OR モードの切り替え対応

### レートリミット
- **約5リクエスト/秒/IPアドレス**（グローバル制限）
- 一部エンドポイントはより厳しい制限あり
- 超過時は HTTP 429、持続的な超過は IP バン

### 活用可能性: ★★★☆☆
- タグシステムが充実しており、レコメンドのフィーチャーに活用可能
- マンガ中心であり、ライトノベル・書籍はカバーしていない
- 日本語対応しているが、スキャンレーション中心のため日本の出版情報は不完全
- 当時確認した利用条件ではクレジット表記とスキャンレーショングループの削除要請への対応が必要と記録した。現在の規約を確認する
- 広告・有料サービス利用について当時の制約を記録した。現在の用途適合性を確認する

### 公式ドキュメント
- https://api.mangadex.org/docs/

## 7. Google Books API

### 概要
Google が提供する書籍情報 API。日本語書籍も多数収録。

### エンドポイント・仕様
- **URL**: `https://www.googleapis.com/books/v1/`
- **方式**: REST API (JSON)
- **認証**: API キー推奨（なしでも一部利用可）
- **料金**: 調査時は無料（API キーは Google Cloud Console で取得）と記録。現行条件は要確認

### 主要エンドポイント
- `GET /volumes?q={query}` - 書籍検索
- `GET /volumes/{id}` - 書籍詳細
- `country=JP` パラメータで日本向けコンテンツに絞り込み可能

### 取得できるデータ
- タイトル、著者、出版社、出版日
- あらすじ（description）
- カテゴリ（categories）
- ページ数
- ISBN (10/13)
- 表紙画像（サムネイル）
- 評価（averageRating, ratingsCount）
- プレビューリンク
- 言語

### レートリミット
- API キーなし: 非常に少ない
- API キーあり: 1日1,000リクエスト（無料枠）

### 活用可能性: ★★★★☆
- 当時の調査では日本語書籍を含む結果を確認した（収録範囲は要再測定）
- あらすじ・カテゴリ情報が取得できる
- 無料で手軽に始められる
- ただしエンタメ特有の詳細タグ（異世界転生、叙述トリック等）はない
- カテゴリは大まかな分類のみ
- ISBN からの書籍情報取得の「つなぎ」として非常に有用

### 公式ドキュメント
- https://developers.google.com/books/docs/v1/using

## 9. 国立国会図書館サーチ API (NDL Search)

### 概要
公的な書誌データベース。日本で出版された資料を広い範囲で収録するが、資料種別・収録条件・更新状況による差がある（当時の調査メモ）。

### エンドポイント・仕様
- **OpenSearch**: `https://ndlsearch.ndl.go.jp/api/opensearch`
- **SRU**: `https://ndlsearch.ndl.go.jp/api/sru`
- **方式**: REST (XML レスポンス: RSS2.0 / DC-NDL / RDF)
- **認証**: 不要
- **料金**: 調査時は無料と記録（現行条件は要確認）

### 取得できるデータ
- タイトル、著者、出版社、出版日
- ISBN
- NDL 書誌 ID
- 件名（subject）
- 分類（NDC: 日本十進分類法）
- 書影画像（書影 API: 非営利目的に限定）
- シリーズ情報

### レートリミット
- 1リクエストあたり最大500件取得
- 明確なレートリミットの公式文書なし（常識的な範囲で利用）

### 活用可能性: ★★★☆☆
- 日本で出版された書籍の収録範囲が広い可能性がある（網羅性は一次資料と対象資料で確認する）
- NDC 分類でジャンル別の絞り込みが可能
- ただしエンタメ特有の詳細タグはない
- 初回調査ではあらすじ情報が少なかった
- XML レスポンスの解析がやや煩雑
- 基本書誌データの「正」のソースとして信頼性が高い

### 公式ドキュメント
- https://ndlsearch.ndl.go.jp/help/api/specifications

## 11. Bangumi API

### 概要
中国発のアニメ・マンガ・ゲーム・書籍のトラッキングプラットフォーム。日本の作品データが豊富。

### エンドポイント・仕様
- **URL**: `https://api.bgm.tv/` (v0)
- **方式**: REST API (JSON:API)
- **認証**: OAuth2（公開データの検索は認証なしで可能）
- **料金**: 調査時は無料と記録（現行条件は要確認）

### 主要エンドポイント
- `GET /v0/search/subjects` - 作品検索
- `GET /calendar` - 放送スケジュール
- 作品（subject）タイプ: アニメ, マンガ, 書籍, ゲーム, 音楽

### 取得できるデータ
- タイトル（日本語・中国語）
- あらすじ

## 12. カーリル図書館 API

### 概要
全国の図書館の蔵書をリアルタイム検索できる API。

### エンドポイント・仕様
- **URL**: `https://api.calil.jp/`
- **方式**: REST API
- **認証**: API キー必要（無料で発行）
- **料金**: 調査時は無料と記録（現行条件は要確認）

### 取得できるデータ
- 全国図書館の蔵書有無・貸出状況
- 図書館情報（名称、住所、URL等）

### 活用可能性: ★★☆☆☆
- 書籍レコメンド後の「最寄り図書館で借りられるか」の付加情報として有用
- 書誌情報自体は取得できない（蔵書検索のみ）
- レコメンドシステムの補助機能向き

- https://calil.jp/doc/api.html
