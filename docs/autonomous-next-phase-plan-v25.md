# 日本のライトノベルを必須対象にする収録・統合計画

更新: 2026-10-25 09:10 JST。[v24](autonomous-next-phase-plan-v24.md)を更新する。無料資料と既存Codexだけを使い、購入・外注・本人による追加入力や評価は求めない。通常の判断、実装、確認、commit・pushはこちらで行う。日本のライトノベルの収録不足を、世界小説全般の分類数拡大より優先する。変動する件数と検証結果は[進捗](light-novels-progress-v1.md)に集約する。

## 目標と現在地

日本のライトノベルを、世界小説の推薦システムの必須対象として扱う。現行の主要レーベルだけでなく、旧作・廃刊レーベル、女性向け、Web小説の書籍化、電子限定作品を対象にする。「魔法科高校の劣等生」は検索・詳細・好み指定・推薦まで確認済みだが、日本のライトノベルをほぼ網羅した段階ではない。

シリーズの登録・版確認・出版社書誌対応・内容分類は、それぞれ別の進捗として管理する。現在の件数は[進捗の「現在使える範囲」](light-novels-progress-v1.md#現在使える範囲)を参照する。候補書誌や取得した商品一覧を、そのまま推薦可能な作品数へ換算しない。

新しい資料は取得前に無料での利用条件とアクセス制御を確認し、AI入力・表示・再配布・商用利用を用途別に判定する。書誌を利用できても紹介文や画像まで許可されたとは扱わない。

## 照合と分類の基準

ISBN・完全な書名・巻次・著者役割・出版社・レーベルなどの複合根拠で対応を確認する。出版社サイトの現在の運営元と、各書誌に記録された出版者を分け、旧出版社名を現在名へ一括変換しない。版限定の表記対応を全作品の別名規則へ広げない。漫画化、アニメ化、合本、特典付き商品を原作シリーズへ一括統合しない。

出版社公式の名称・出版者・書籍ISBNが確認できる場合は、小説種別がまだ不明でも初回NDL候補検索へ進める。発見のための取得と、小説・ライトノベル・原作品の認定を分ける。小説証人の不足だけを理由に候補発見まで永久に保留せず、明示的な非小説資料は別に扱う。

分類はジャンル、テーマ、物語構造、主人公属性、文体、雰囲気を多ラベルで扱い、関連度・未校正の信頼度・根拠・分類版を保存する。本文根拠のない文体は不明のままにする。採用済みの内容特徴を利用し、既存分類の再実行や全件分類を収録拡張の前提にしない。新規分類を再開する場合は、用途条件が確認できる新しい内容資料のある差分だけに限定し、既存Sol CLIの分類と別呼出しの審査を独立した入力単位で並列化する。

独立した正解集合のない分類精度、信頼度の校正、本人向け推薦改善は未評価として報告する。本人の採点や外部評価の購入は要求しない。

## 無駄を増やさない運用と完了判定

保存済み原資料と既存の検証結果を再利用し、新しい根拠・変更のある候補だけを再処理する。全件再取得、同じ入力の再分類、固定20シリーズの再確認、世界小説2万分類の全件再監査は繰り返さない。関連試験は変更時に実行し、全体CIはまとまった実装の区切りに一度行う。経過時間や残量は実測から更新し、根拠のない完了予定を出さない。

全国の全刊行物という確定分母はないため、網羅率の数字を作らない。出版社・レーベル・年代・形式ごとに、一覧総数、取得済み、版確認済み、シリーズ対応済み、未対応、保留、対象外を示す。追加候補129枠は境界領域73・主要候補12・Web書籍化20・歴史的候補24を含み、廃刊レーベル129という集合ではない。未確認の境界を残作業として管理し、調査済みの枠を同じ条件で再検索しない。主要な既知の不足を解消し、残る取得不能・権利不明・電子限定等を説明できた時点で収録範囲を評価する。1,000シリーズ・500内容分類は通過点である。

ライトノベルの収録と利用が安定した後、差分更新へ移し、世界小説の内容分類を3万・5万・10万作品以上へ広げる。ToC化は用途条件、履歴管理、応答時間、公開構成を確認して判断する。
