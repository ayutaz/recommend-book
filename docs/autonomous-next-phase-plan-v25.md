## ここからの優先順序

直近の完了単位は、世界小説の詳細分類を20,020から21,000へ増やし、新規分を検索・詳細・推薦へ反映することです。あと980作品の採用が必要です。用途審査済み144作品は採用済み20を含むため、未採用の準備分は124作品で、その全件採用を仮定しても追加で856作品分の資料が必要です。まず後続54作品の処理結果を確認して取り込み、残る準備済み入力へ進みます。次の4項目を完了するまで、3万・5万・10万への全体拡張を完了とは扱いません。

| 順序 | 実施内容 | 完了条件 |
|---|---|---|
| 1. 新規資料の確保 | 既存分類・過去と同じ入力を除外し、用途条件と物語内容を確認した資料だけを収集。準備できた小バッチから分類へ渡す | 次の分類バッチに必要な、重複のない根拠付き入力が揃う |
| 2. 新規1,000作品の分類・別審査 | Sol CLIで分類と別審査を実行。最初の小バッチを確認して最大8ワーカーへ拡張し、出典・関連度・未校正の信頼度・不明値を保持 | 既存20,000作品を保持して新規1,000作品を採用。各バッチで失敗率5%以下、表示特徴の採用率70%以上。これは分類精度の保証ではない |
| 3. アプリへの反映と提供 | 完了バッチから順次DBへ取り込み、検索・詳細・推薦で新規特徴を確認。旧行と読書状態の保持、関連試験、文書更新、commit・pushまで実施 | 21,000分類がDBにあり、新規分の実動作と変更コードの検証結果を確認できる |
| 4. ライトノベル補完と応答時間改善 | 上記と並行し、内容根拠のある小規模な差分を追加。推薦の不要な書誌処理を減らし、同条件で結果と待ち時間を比較 | 新しい内容特徴がアプリで使え、出典検証と推薦結果を保った実測改善がある |

『神様のメモ帳』は今回、新しい資料による分類・別審査、DB採用、実HTTPの詳細表示まで完了し、内容特徴ありシリーズは585となりました。ジャンル指定時の推薦は、前区間と同じ公開結果を保って54.38秒で返しました。別実行の各1回の測定で、全条件の速度保証ではありません。世界小説は最初の20作品の分類・別審査・出力審査・DB取込と実HTTPの検索・詳細・推薦確認まで完了し、20,020分類になりました。後続54作品は18:49 JSTに最大8並列での稼働を確認しました。起動前の補助モジュール不足は専用入口で修正し、収集段階でも既存分類済みQIDを除外します。

日本全国の刊行物の確定や全件分類の完成を、次の有用な差分を届ける条件にはしません。原204取得枠や過去のv6集計を全国作品数・残数の分母には使いません。

## 世界小説の3万・5万・10万分類へ進む

日本のライトノベルの既知の検索漏れと優先取得枠を処理し、残る空白を説明でき、差分更新へ移せる区間から世界小説の拡張を並行して進めます。全国の全刊行物の確定を待ち続ける計画にはしません。

| 規模 | 進め方と移行条件 |
|---|---|
| 3万分類 | 既存2万分類・履歴を保持し、新たに用途条件と内容根拠が揃う差分を有限バッチで追加。費用・失敗率・所要時間・採用率を実測し、検索と推薦へ届ける |
| 5万分類 | 3万段階で差分取り込み・保留管理・利用量集計が安定した範囲を拡張。年代・国・言語・ジャンルの偏りと資料の空白を報告する |
| 10万分類以上 | 根拠のある対象を継続追加し、更新可能性と応答時間を確認する。件数目標のために不明値を推定で埋めたり、権利不明の本文を入力したりしない |

独立精度・校正・本人向け改善は未評価です。本人の採点を追加工数として求めず、既存評価と確実に接続できた範囲だけを利用します。LLMの別審査と独立した正解集合は区別します。全国網羅や拡張全体の完了日時は断定せず、次の有限バッチの実測で見積もります。

10万分類以降は、対象データの用途条件、必要な帰属表示、差分更新、検索・推薦の応答時間と復旧手順を整え、ToC向けの提供候補へ進みます。独立した分類精度や個人推薦の改善が未確認のまま、件数だけでサービス品質を保証しません。無料の評価資料や既存履歴で確認できる範囲を示し、本人への追加採点は求めません。

## 処理量と用途条件

- 保存資料・成功証跡を再利用し、新しい根拠・未登録ID・変更のある差分だけを処理します。完了済み742試行や導入文のみで停止した旧経路を同じ入力で再送しません。後から得た新しいあらすじ等は別入力として判定します。
- 独立した取得元・照合・実装・レビューは並列化します。同一取得元へのアクセスとDB書込みは各一系統にし、無制限な再試行はしません。Sol CLIは既存契約の上限8ワーカー以内で実測に応じて調整します。
- テスト成功、実HTTP・画面、収録範囲、分類品質、商用提供の成立を別々に報告します。応答の長い待ち時間は未解決事項として扱います。
- 取得・AI入力・表示・再配布・商用利用を資料と用途ごとに確認します。書誌への許可を紹介文・本文・表紙へ広げません。根拠のない原言語・巻順・文体は不明のまま保ちます。
- 原資料・DB・個人履歴・認証情報はGitへ含めません。既存世界小説2万分類と読書状態を保持し、全国網羅や推薦精度を件数だけで主張しません。
