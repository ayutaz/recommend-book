# 日本のライトノベルを必須対象にする収録・統合計画

更新: 2026-10-25。[v24](autonomous-next-phase-plan-v24.md)の後続計画。日本のライトノベルの収録不足を、世界小説の分類数拡大より優先する。無料資料と既存Codexだけを使い、購入・外注・本人による追加入力や評価は求めない。通常の判断、実装、確認、commit・pushはこちらで行う。

## 目標と現在地

現行・旧作・廃刊レーベル、男性向け・女性向け、Web小説の書籍化、電子限定作品まで対象にする。一般小説との境界や翻訳作品は出典に従って区別し、日本語の書誌を日本語原著と決めつけない。シリーズ名・各巻名・別題・著者で検索し、好きな作品や読書状態から別作品を推薦できることを目指す。

現在は2,197物語シリーズ、内容特徴572シリーズを登録済み。「魔法科高校の劣等生」は検索・詳細・好み指定・推薦を確認済み。版候補87,278件にはラノベ未確定の書誌も含むため、推薦可能な作品数へ換算しない。シリーズ・グループとの所属関係は5,031件。出版社書誌との対応4,215件と、出版社の掲載参照との対応21件は別に数える。確認値と過去の作業記録は[進捗](light-novels-progress-v1.md)に集約する。日本のライトノベルをほぼ網羅した段階ではない。

## 収録範囲と優先順位

主要レーベルの現行作品だけで終えず、旧作・廃刊レーベル、女性向け、Web発の書籍化、単行本・電子限定を順に照合する。電撃・富士見・スニーカー・MF・ファミ通・GA・ガガガ・HJ・オーバーラップなどと、コバルト・ビーンズ・ビーズログ・一迅社などは、既取得分を再収集せず公式一覧との不足を確認する枠とする。列挙した名称を全国の全対象とは扱わず、新しいレーベルや刊行形態も台帳へ追加する。

対象の優先順位は、①報告された検索漏れ、②主要レーベルの未接続作品、③旧作・女性向け・電子限定などの不足、④新しい内容資料に基づく分類とする。分類がない作品も書誌検索から利用できるようにし、全件分類の完了を収録拡張の前提にしない。日本のライトノベルが安定して検索・推薦に使えることを、世界小説の分類件数拡大より先に満たす。

## 実施順序

| 段階 | 実施内容 | 完了を判断する条件 |
|---|---|---|
| 1. 未接続の書誌を追加 | 取得済み資料とDBのID差分だけを採用する。富士見L、講談社BOX／タイガ、星海社FICTIONS／文庫、キャラの6枠とシフォンの差分採用は終了した。次の未取得枠も有限な範囲で接続する。出典・実叢書欄・言語・出版者・分類記号を保持し、未同定でも候補として検索可能にする | 新規IDの採用結果と旧IDの保持を確認。名称検索のヒットと実際のレーベル所属を区別し、候補・不明の表示が働く |
| 2. 作品・シリーズ・版を対応付ける | 公式一覧とNDL主書誌の複合根拠で、シリーズ、各巻の作品、紙・電子・文庫版を分けて接続する。完全題・巻次・著者役割・ISBN・出版情報を確認し、同名作品、短編集、翻訳、漫画化を区別する | 根拠のある関係だけを保存。正式名・各巻名・別題で検索でき、巻違い・誤結合を検査できる。未証明は独立した書誌として残す |
| 3. 内容分類と推薦へ接続 | 用途条件と内容根拠のある未試行差分だけをSol CLIで分類し、別呼出しで審査する。ジャンル、テーマ、構造、主人公属性、文体、雰囲気に関連度・未校正の信頼度・根拠を付ける | 書誌ジャンルと内容特徴を区別して推薦理由を表示。同一シリーズ・同一作品の別版の重複を抑え、既読除外と状態不明の扱いを確認。根拠のない軸はunknownのまま |
| 4. 不足と利用品質を確認して反映 | レーベル・年代・形式別に取得済み、対応済み、保留、未取得、対象外を整理する。変更箇所の試験・実HTTP・必要な画面確認・実装更新時の両OS CIを行い、文書・commit・push・PRへ反映する | 既知の大量未対応を解消し、残る取得不能・電子限定・権利不明を説明できる。分類数や検索件数だけで「ほぼ網羅」と判定しない |

各提供元で取得→差分採用→名寄せ→検索確認を一区切りにする。取得だけの一覧を増やし続けず、内容未分類でも検索に使える状態を先に作る。第4段階の不足を次の取得枠へ戻し、対象範囲を広げる。

## 直近の実行単位

1. **直近の取り込みを利用画面へ反映する。** 前区間の新1,777候補に続き、ダリアシリーズ・ルネッタブックスから新169候補、二次元ドリーム文庫・ノベルズから新663候補を採用した。著者とイラスト担当を同じ主書誌の直接欄で区別し、『五年霊組こわいもの係』13版のシリーズ所属も追加した。オレンジ文庫の61版候補は掲載参照21件を追加し、40件を保留した。実装7788635をcommit・pushしてローカルサーバーへ反映し、代表2版の実HTTPとChromeの掲載参照表示を確認した。両OS CIの結果確認とPRへの記録を残す。次の差分は保存済みKADOKAWA電子専売51掲載書誌のローカル検索で、まだ実装中・DB未採用である。DB採用、稼働サーバー、配布済み実装への反映を分けて報告する。
2. **未接続候補を作品検索へ結び付ける。** 出版社一覧と保存済みNDL書誌の差分から、完全題・巻次・著者役割・出版情報のそろう候補を優先する。既存の成功した照合方法を再利用し、同じ失敗入力は新しい根拠が得られるまで再実行しない。出版社の掲載参照との対応は物語シリーズや同一版の証明へ読み替えず、内容分類や日本語原著の確定数にも加算しない。SQEX公式の一括取込みは用途別条件未確定の保留を維持する。
3. **残る未取得枠と0件の補完を進める。** 上記832新候補はレーベル別台帳v6へ反映済み。ナイトスターブックス・ビギニングノベルズの0件結果は未収録作品がない証明にしない。スニーカー・G文庫などの分類違い、一次名称未確認、既取得の広い名称に含まれる枠を区別する。ロサージュは保存済み23書誌に実叢書名「Rosage Novels」があり、新しい発見根拠として既取得を再利用する。コスミックセシル文庫やラルーナ文庫オリジナル等の重なる発見範囲も再検索せず、歴史的な全刊行物の同一性は未確認として残す。新潮文庫nex／SKYHIGH文庫などは新しい一次表記が得られた場合だけ補完する。広い一般文庫全体をラノベと認定しない。
4. **分類は新しい内容根拠のある差分に限定する。** 導入文だけの2件は分類・別審査を終えたが、表示採用率50%で既定の70%基準に届かずDB採用0のまま停止した。残る44件へ自動拡大しない。完了済み742試行を同じ入力で再送せず、内容資料のない作品も検索できる状態を保つ。

原204取得枠は作業台帳であり、全国の作品数や網羅率の分母ではない。v6の集計は取得証跡161・UI0/rawなし13・未取得17・その他13。元の枠IDと新しい取得枠を明示対応で照合し、候補件数から枠数を推計していない。検索終端もレーベルの全刊行物取得を意味しない。元の204枠にない名称も発見IDを設け、対象範囲の拡張として記録する。

## 次段階へ進む条件

- **検索・統合**：報告された検索漏れを回帰対象に加え、シリーズ名・各巻名・別題・著者で検索できることを確認する。同名別作品、漫画版、翻訳、合本の誤統合を防ぎ、未同定の書誌も根拠付きで表示する。
- **収録範囲**：対象に選んだ各公式一覧の終端と掲載件数を記録し、登録済み・未接続・保留・対象外を照合する。代表作が見つかるだけで網羅を主張せず、電子限定・旧作などの残る空白を明示する。
- **分類・推薦**：用途条件と内容根拠がある新規入力だけを分類する。根拠付きの関連度・信頼度・不明値を保持し、別審査と規則検査を行う。同じ作品の別版や同一シリーズが推薦を占めないこと、既読除外が働くことを確認する。本人の採点を必須にしない。
- **継続更新**：収録と利用が安定した対象は差分更新へ移す。新刊・改題・レーベル変更を追跡し、日本のライトノベルの更新を保ちながら世界小説の3万・5万・10万作品以上の詳細分類へ進む。

## 利用条件・分類品質

取得、AI入力、表示、再配布、商用利用の条件は用途別に記録する。書誌の利用許可を紹介文・本文・表紙画像へ広げない。用途不明の文章をLLMへ渡さず、書誌や出典リンクだけを扱える範囲と分ける。将来のToC提供は公開対象と用途条件が成立した段階で判断する。

分類は根拠区間、モデル・分類体系・入力の版、関連度、信頼度を保存する。本文根拠のない文体は不明のままにする。LLMの別審査は品質検査であり、独立した正解集合ではない。独立精度・信頼度校正・本人向け推薦改善は、証拠が得られるまで未評価と報告し、本人の採点を完成条件にしない。

## 時間と処理量を抑える運用

- 保存資料と既存の成功証跡を再利用し、新しい根拠・変更・未登録IDのある差分だけを処理する。全件再取得・原資料の再監査・同じ入力の再分類を繰り返さない。
- 独立する取得元、名寄せ、実装、レビューを並列化する。同一提供元へのアクセスとDB書込みは各一系統とし、失敗時の無制限な自動再試行をしない。
- Sol CLIは独立した未試行入力を並列実行する。既存の検証済み契約を使い、上限8ワーカー以内で失敗率と実測時間を見て調整する。
- 試験は変更箇所に合わせる。実装08d9530のUbuntu・Windows CIは両方成功した。実装7788635の照合・表示変更は別のCIで確認中。次の電子専売の参照実装はさらに別差分として検証する。データ・計画だけの更新で全件CIを再起動しない。計画更新だけを理由に追加収集やモデル処理を起動しない。
- 世界小説の既存2万分類と読書状態を保持する。原資料・DB・読書履歴はGitへ含めない。

固定件数への到達は通過点とする。既知の取得枠の不足と対応保留を解消し、残る空白を説明できるようになってから収録範囲を評価する。所要時間は次の実行単位の実測から更新し、全国網羅の完了日時は現時点で断定しない。ライトノベルの収録・利用が安定した後、差分更新へ移して世界小説の3万・5万・10万作品以上へ拡張する。
