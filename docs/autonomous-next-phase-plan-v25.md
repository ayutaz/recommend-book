# 日本のライトノベルを必須対象にする収録・統合計画

更新: 2026-10-25 08:06 JST。[v24](autonomous-next-phase-plan-v24.md)を更新する。無料資料と既存Codexだけを使い、購入・外注・本人による追加入力や評価は求めない。通常の判断、実装、確認、commit・pushはこちらで行う。日本のライトノベルの収録不足を、世界小説全般の分類数拡大より優先する。変動する件数と検証結果は[進捗](light-novels-progress-v1.md)に集約する。

## 目標と現在地

日本のライトノベルを、世界小説の推薦システムの必須対象として扱う。現行の主要レーベルだけでなく、旧作・廃刊レーベル、女性向け、Web小説の書籍化、電子限定作品を対象にする。「魔法科高校の劣等生」は検索・詳細・好み指定・推薦まで確認済みだが、日本のライトノベルをほぼ網羅した段階ではない。

シリーズの登録・版確認・出版社書誌対応・内容分類は、それぞれ別の進捗として管理する。現在の件数は[進捗の「現在使える範囲」](light-novels-progress-v1.md#現在使える範囲)を参照する。候補書誌や取得した商品一覧を、そのまま推薦可能な作品数へ換算しない。

新しい資料は取得前に無料での利用条件とアクセス制御を確認し、AI入力・表示・再配布・商用利用を用途別に判定する。書誌を利用できても紹介文や画像まで許可されたとは扱わない。

## ここからの実施順序

| 順序 | 作業 | 次へ進む条件 |
|---|---|---|
| 1. 取得済み資料を検索できる書誌へ接続 | SB215群の追加を終えたため、次はHJ文庫137件を公式索引上の掲載単位として検証する。その後HJノベルス39件、アリアンローズ49件を同じ方針で進め、双葉社の未所属26参照も扱う | 確認できた書名・別題・掲載クレジットで検索できる。各巻一覧のない掲載単位は所属不明を示し、架空の各巻・物語シリーズを作らない。SBの未完8群は保留。旧ID・版確認・分類・履歴を保持する |
| 2. 不足する取得枠を埋める | 出版社・レーベル別台帳で未取得・取得済み未接続を分け、女性向け・電子専売と旧作・廃刊の不足を優先する。保存済みコバルト、ホワイトハート、ティーンズハート、ソノラマ等を再利用し、徳間・C★・ログアウト等の不足だけを追加確認する | 各枠の総数・最終ページ・重複・取得失敗を記録する。GC系のHTTP 500や講談社のメンテナンス転送は保留を残し、新しい根拠なく同じ失敗や回避経路を繰り返さない |
| 3. 名寄せ・内容分類・推薦へ接続 | シリーズ名・各巻の固有題・別題・著者で検索できるようにする。公式の明示関係とNDL主書誌を照合する。新たに用途条件と内容根拠が確認できた差分だけをSol CLIで多ラベル分類し、別呼出しで審査する | シリーズ自身や同一作品の版が推薦を占めず、既読除外と推薦理由が働く。分類は関連度・未校正の信頼度・根拠を保持する。未分類の書誌も検索でき、特徴不明を推測で埋めない |
| 4. 品質・範囲を確認して反映 | 誤結合、巻違い、重複、出典、取得・AI入力・表示・再配布・商用利用の条件を確認する。変更した経路の実HTTP・画面確認と確定実装のUbuntu／Windows Python 3.14 CIを行う | 結果と残作業を文書へ反映し、commit・push・PRにまとめる。主要な取得枠・大量未対応が残る間は「ほぼ網羅」や完成としない |

取得と接続を大きな二工程に分離せず、出版社ごとに取得→照合→検索確認まで進める。取得だけ済んだ一覧を増やし続けない。並列化は独立する提供元・実装・レビューに用い、同じ提供元へのアクセスとDB書込みはそれぞれ一系統にする。

## 直近の接続結果と次の実行単位

1. **双葉社の未接続114掲載グループは採用済み。** Ｍノベルス系190グループ中、NDL接続済み76グループと残114掲載グループを別の型で保存した。追加114群は349商品参照を持ち、代表例の検索・詳細・根拠不足時の類似APIを確認した。掲載グループを物語シリーズへ昇格させず、紙・電子の同版性や不明な著者を補わない。[設計](light-novel-publisher-source-group-proposal-v1.md)を参照。
2. **KADOKAWA追加5レーベルは4,219版を追加確認。** 6,311商品参照・318ページの差分を正式検証し、保存NDL書誌と照合した。2,092参照は有効ISBNなし324件と未証明1,768件として保留。旧4レーベルの原資料再取得・再照合は行わず、版数を新規シリーズ数へ換算しない。同じ書誌・著者根拠は既存の所属照合でも対象だったため、同入力の全件再照合は挟まない。
3. **オーバーラップは279書誌対応を追加。** 新規630詳細だけを照合し、351参照を未証明として保留した。別の構造差5件と旧4詳細も保持する。無標記の人名を著者と推定せず、ラノベ区分・原作品同一性を不明のまま残す。保留の再取得は新しい根拠がある場合に限る。
4. **オレンジ文庫97群・455参照とeコバルト211群・1,487参照、未所属324参照は採用済み。** 掲載グループと独立書誌を別の型で検索・詳細へ接続した。著者別索引の表示を個別書誌の著者役割へ変換せず、同題アンソロジーも別の掲載単位として保持した。既Cobaltの8正式参照のうち実採用された物語シリーズは4件であり、211群から8件を一律除外しない。
5. **SB215掲載グループ・1,029商品参照は採用済み。** 最初の採用は表紙画像の説明と正式書名の混同を検出して保存前に停止した。正式な書名欄だけを使うよう修正し、対象差分を採用した。未完8群と不明な著者役割・ISBN等は保留し、紹介文や画像等への用途許可を推定しない。

直近は次の差分に限定する。

- **HJ文庫137件を先に接続**：完全な索引題と固有URLのある137候補が、保存済み索引17ページにある。次はこの範囲だけを認証する。子書誌の明示関係がないため、索引カード確認と各巻一覧の完了を分け、商品総数・所属は不明とする。既存の親子確認済みグループの契約は緩めない。候補台帳の準備だけではDB採用済みとしない。
- **初期取得枠の残差**：元の1,365公式参照は、既採用917と今回のSB215を合わせて1,132参照が接続済みとなった。未対応233はHJ文庫137・HJノベルス39・アリアンローズ49・SB未完8である。これは既存の採用証跡と非重複な追加から求めた差分で、物語シリーズ数・日本全体の網羅率ではない。全1,365原資料の再監査は挟まない。
- **未所属参照の拡張**：eコバルトで実装した掲載書誌の単位を、双葉社の未所属26参照などへ広げる。別提供元の根拠と用途条件を確認し、作品やシリーズを新造しない。
- **関連単位の表示**：同題アンソロジー2群は、掲載見出しの人名表示で一覧から区別できるようにした。独立した証拠を持つ既存Cobalt4物語シリーズと掲載群の出典上の関連表示は残作業。ID・分類・履歴は統合しない。

これらをまとめた実装の区切りで関連試験、変更経路の実HTTP・画面、両OS CI、文書、commit・pushを行う。取得待ちの間に既存の成功済み処理を繰り返さない。

検索可能にする工程を内容分類より先に進める。保存済みの許可資料にあらすじ節がある未試行76候補は、8・37・31件に分けた分類・別審査・DB採用を終え、モデル処理を停止した。導入文のみ46件は内容支持を確認するまで別枠とし、内容資料のない作品は未分類のまま検索へ出す。新たな分類は新しい根拠のある差分だけを対象にし、分類数を増やすための資料購入や同じ入力の再分類は行わない。

## 照合と分類の基準

ISBN・完全な書名・巻次・著者役割・出版社・レーベルなどの複合根拠で対応を確認する。出版社サイトの現在の運営元と、各書誌に記録された出版者を分け、旧出版社名を現在名へ一括変換しない。版限定の表記対応を全作品の別名規則へ広げない。漫画化、アニメ化、合本、特典付き商品を原作シリーズへ一括統合しない。

分類はジャンル、テーマ、物語構造、主人公属性、文体、雰囲気を多ラベルで扱い、関連度・未校正の信頼度・根拠・分類版を保存する。本文根拠のない文体は不明のままにする。採用済みの内容特徴を利用し、既存分類の再実行や全件分類を収録拡張の前提にしない。新規分類を再開する場合は、用途条件が確認できる新しい内容資料のある差分だけに限定し、既存Sol CLIの分類と別呼出しの審査を独立した入力単位で並列化する。

独立した正解集合のない分類精度、信頼度の校正、本人向け推薦改善は未評価として報告する。本人の採点や外部評価の購入は要求しない。

## 無駄を増やさない運用と完了判定

保存済み原資料と既存の検証結果を再利用し、新しい根拠・変更のある候補だけを再処理する。全件再取得、同じ入力の再分類、固定20シリーズの再確認、世界小説2万分類の全件再監査は繰り返さない。関連試験は変更時に実行し、全体CIはまとまった実装の区切りに一度行う。経過時間や残量は実測から更新し、根拠のない完了予定を出さない。

全国の全刊行物という確定分母はないため、網羅率の数字を作らない。出版社・レーベル・年代・形式ごとに、一覧総数、取得済み、版確認済み、シリーズ対応済み、未対応、保留、対象外を示す。既存の旧作・廃刊候補129枠等の境界未確認も残作業として扱い、調査済みの枠を同じ条件で再検索しない。主要な既知の不足を解消し、残る取得不能・権利不明・電子限定等を説明できた時点で収録範囲を評価する。1,000シリーズ・500内容分類は通過点である。

ライトノベルの収録と利用が安定した後、差分更新へ移し、世界小説の内容分類を3万・5万・10万作品以上へ広げる。ToC化は用途条件、履歴管理、応答時間、公開構成を確認して判断する。
