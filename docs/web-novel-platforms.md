## 各プラットフォーム詳細

### カクヨム（KADOKAWA / はてな運営）

- **公式API**: 当時公式APIを確認できず
- **利用規約**: 当時参照した第14条にソースコード解析行為の禁止と読める記載があった。現行条項を再確認する
- **代替手段**: Atomフィードで作品更新情報（タイトル、更新日時）のみ取得可能。あらすじ・タグは含まれない
- 2025年3月末の合併について当時の情報として記録（現在のサービス状況は要確認）

### アルファポリス

- **公式API**: 当時公式APIを確認できず
- **利用規約・運営回答**: 当時、「スクレイピングによるデータ収集は禁止」との回答を記録した。現在の条件は運営者に確認する
- 自作品のテキスト一括ダウンロード機能のみあり（投稿者本人限定）

### ハーメルン（syosetu.org）

- **公式API**: 当時公式APIを確認できず
- 個人運営の二次創作小説投稿サイト。約11万作品、約35万ユーザーという当時の記録がある（現在の規模は要確認）
- 利用規約にスクレイピングの明確な禁止規定は未確認だが、個人運営サイトへの大量アクセスは道義的に問題あり

### pixiv小説

- **公式API**: 当時公式APIを確認できず（内部App APIがリバースエンジニアリングで解析されたとの記録）
- **認証**: OAuth 2.0必須（refresh_token事前取得が必要）
- **取得データ**: タイトル、あらすじ、タグ、ブックマーク数、閲覧数、本文
- **主要ライブラリ**: [pixivpy](https://github.com/upbit/pixivpy)（Python）
- **リスク**: 非公式APIのため仕様変更リスクが常にある（2024年3月に大幅変更あり）。大量アクセスはアカウント停止の可能性

### エブリスタ

- **公式API**: 当時公式APIを確認できず
- 当時の運営回答として、目視でのデータ分析とソフトウェア・プログラムを用いた分析を区別する説明を記録した。現在の条件は再確認する

### 青空文庫（著作権切れ作品）

- CSVファイルで全作品の書誌情報を公開（約16,000作品）
- **ZORAPI**: サードパーティAPI。文字数、書き出し、アクセス数なども取得可能
- エンタメ系最新作品ではないが、日本語テキスト分析の学習データとして利用可能

## 結論

この調査範囲で、公式APIの利用例を確認できたのは**小説家になろうAPI**だった。他のプラットフォームについては、当時公式APIを確認できなかったり、フィード・非公式手段・運営回答など情報の種類が異なったりした。したがって、外部からのプログラム取得が一律に禁止されている、または小説家になろうAPIが唯一利用可能だとは結論づけない。候補ごとに現行規約、ライセンス、許諾、負荷制限を確認し、必要なら運営者へ問い合わせる。
