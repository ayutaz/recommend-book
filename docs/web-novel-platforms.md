# Web小説プラットフォーム API調査

「小説家になろう」以外の主要プラットフォームのAPI/データ取得手段の調査結果。

## 一覧

| プラットフォーム | 公式API | スクレイピング | 現実的なデータ取得手段 |
|----------------|---------|--------------|---------------------|
| **小説家になろう** | あり | API以外は非推奨 | **なろう小説API** |
| **カクヨム** | なし | 利用規約で禁止 | Atomフィード（限定的） |
| **アルファポリス** | なし | 運営が明確に禁止 | なし |
| **ハーメルン** | なし | 明確な禁止規定は未確認 | なし（個人運営のため自重推奨） |
| **pixiv小説** | 非公式（App API） | 非公式ライブラリ経由 | pixivpy等（リスクあり） |
| **魔法のiらんど** | なし | - | サービス終了（カクヨムに統合） |
| **エブリスタ** | なし | 運営が禁止と回答 | なし |
| **ノベルアップ+** | なし | 不明 | なし（要問い合わせ） |

## 各プラットフォーム詳細

### カクヨム（KADOKAWA / はてな運営）

- **公式API**: なし
- **利用規約**: 第14条でソースコード解析行為を明確に禁止
- **代替手段**: Atomフィードで作品更新情報（タイトル、更新日時）のみ取得可能。あらすじ・タグは含まれない
- 2025年3月末に魔法のiらんどと合併し規模拡大中

### アルファポリス

- **公式API**: なし
- **利用規約**: 運営が「スクレイピングによるデータ収集は禁止。違反時はアクセス禁止処理」と明確に回答
- 自作品のテキスト一括ダウンロード機能のみあり（投稿者本人限定）

### ハーメルン（syosetu.org）

- **公式API**: なし
- 個人運営の二次創作小説投稿サイト。約11万作品、約35万ユーザー
- 利用規約にスクレイピングの明確な禁止規定は未確認だが、個人運営サイトへの大量アクセスは道義的に問題あり

### pixiv小説

- **公式API**: なし（内部App APIがリバースエンジニアリングで解析済み）
- **認証**: OAuth 2.0必須（refresh_token事前取得が必要）
- **取得データ**: タイトル、あらすじ、タグ、ブックマーク数、閲覧数、本文
- **主要ライブラリ**: [pixivpy](https://github.com/upbit/pixivpy)（Python）
- **リスク**: 非公式APIのため仕様変更リスクが常にある（2024年3月に大幅変更あり）。大量アクセスはアカウント停止の可能性

### エブリスタ

- **公式API**: なし
- 運営回答: 「目視でのデータ分析は問題ないが、ソフトウェア・プログラムを用いた分析は禁止」

### 青空文庫（著作権切れ作品）

- CSVファイルで全作品の書誌情報を公開（約16,000作品）
- **ZORAPI**: サードパーティAPI。文字数、書き出し、アクセス数なども取得可能
- エンタメ系最新作品ではないが、日本語テキスト分析の学習データとして利用可能

## 結論

プログラムから安定して合法的にデータ取得できるWeb小説APIは、**小説家になろうAPI が唯一**。他のプラットフォームはいずれも外部からのプログラムによるデータ取得を禁止しており、活用にはプラットフォーム運営との個別交渉が必要。
