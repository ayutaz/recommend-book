# 日本のライトノベルを必須対象にする追加計画

更新: 2026-10-25 01:51 JST。[v22](autonomous-next-phase-plan-v22.md)の実行結果を踏まえた残工程。日本のライトノベルを、世界小説の検索・推薦と並ぶ常設対象にする。無料資料と既存Codexだけを使い、追加費用・外注・本人による入力や採点は求めない。過去の計画と固定証跡は保持する。

## 現在地

魔法科が見つからなかった原因は、未収録に加え、従来の取込みが小説シリーズを対象外としていたことだった。シリーズ・各巻の作品・版を分ける基盤を追加し、魔法科の検索、32巻の書誌表示、好きな作品から30候補を理由・出典付きで表示する経路は、実HTTPとChromeで確認した。

検索可能2,072シリーズ、内容特徴あり504シリーズまで確認済み。固定20シリーズの検索・詳細確認は20/20で、v22の1,000シリーズ・内容特徴500という初期目標を超えた。版の候補件数をシリーズ数に加算しない。全国の収録率、独立した分類精度、確信度の校正、本人向け推薦の改善は未評価である。件数と根拠の詳細は[進捗](light-novels-progress-v1.md)に集約する。

| 1. 取得範囲を確定して完走 | 取得中のNDL固定75レーベルを完走し、保存一次資料で名称確認済みの旧レーベル3枠、その後に歴史候補16名称の初回検索を行う。KADOKAWA主要4レーベル13,974版・701ページを、公開アクセス間隔に従って取得する | 各枠の終端、重複、原資料hash、未取得・0件・保留理由が記録される。検索0件をレーベル不存在や未刊行の証明にしない |
| 2. 保存済み資料を優先して照合 | 出版社のシリーズ一覧・版一覧をNDL書誌と照合する。ISBN、巻次を含む書名構造、著者役割、出版社、レーベルを確認し、表記差で止まる版を解消する | 確認済み版、シリーズへの対応済み、未対応、重複候補を分離する。ISBN一致だけで原作品・シリーズを統合しない |

取得・保存資料の照合・関連試験は独立する範囲でSolの担当を分ける。同じ提供元への取得は一系統、DB書込みも一系統とし、並列化でアクセス間隔や整合性を崩さない。

## 照合を先に改善する理由と境界

固定5,000件のKADOKAWA版では、1,604件を確認済み、3,396件を未照合としている。未照合のうち、保存済みNDLデータにISBNがないものは63件で、多くは同じISBNがあっても書名の巻数位置、著者情報、レーベル表記の違いで止まっている。63件をNDL全体の未収録件数とはしない。追加取得に先立ち、既存資料の構造から照合を改善する。

版照合の新ルールは、公式KADOKAWA文庫と同じ出版社のNDL主書誌に限定する。主書誌の書名・巻次、ISBN、明示された著者役割などの根拠を保存する。典拠URIがない場合も未知として保持し、原作品・シリーズの本人同定条件へ広げない。現時点では関連78試験と既存1,604件の旧証拠の再生一致を確認した段階で、新ルールの実DB反映は未実施である。

同じ固定枠のISBNなし449商品は、保存公式資料の商品形態定義では電子専売に当たる。ISBNを作ったり紙版へ推定接続したりせず、電子版の識別子・合本構成・原作品との関係を別に扱う。検索で表示できる書誌と、シリーズ所属まで確認済みの版を区別する。

## 収録範囲の判定

全国のライトノベル全作品に対する確定した分母はないため、件数だけで網羅率を作らない。出版社公式の有限一覧とNDL書誌を突き合わせ、取得枠ごとに「一覧総数／取得済み／照合済み／未対応／保留／対象外」を報告する。一覧から消えた旧作や電子専売など、その枠の外側も明記する。

HJ文庫・HJノベルス・アリアンローズ・SBのシリーズ一覧に加え、KADOKAWA、集英社、一迅社の取得済み一覧を再利用する。Irisの2015〜2026年557版の詳細取得は終端済みだが、NDLとの同定は別工程であり、2015年以前を含む全刊行物の回収とはしない。歴史レーベルや他出版社の入口取得を、一覧完走と数えない。ライト文芸・児童・漫画・BL/TLなどの境界は名称だけで一括採用・排除しない。

書誌、紹介文、画像、本文について、AI入力・画面表示・再配布・商用利用の条件を用途別に確認して記録する。出版社一覧は発見・照合に使い、取得できたことを宣伝文や本文の利用許可に転用しない。原資料・DB・個人履歴はGit対象外に置く。

## 分類・検証を繰り返さない

内容特徴504シリーズで初期目標を満たし、分類・別審査・全履歴集計は終了している。現在の収録拡張のために成功済み・失敗済み入力を再送せず、予備分類も起動しない。書誌だけのシリーズも検索と根拠のあるジャンル推薦へ接続し、内容分類済みとは表示しない。文体など根拠のない軸は不明のまま扱う。

固定20例、既存世界小説2万分類と履歴の保存値比較、分類全履歴の監査は確認済みの証跡を再利用する。新しい変更・失敗に関係する試験だけを追加し、取得とDB反映が揃った時点でライトノベル台帳の統合監査を一度行う。確定実装の両OS CIはまとめて実行する。直前の実装`6e9ba5a`のCIはUbuntu成功・Windows未成功であり、旧実装の両OS成功で代用しない。

## その先

日本のライトノベルの検索・推薦を利用可能な状態に保ち、未収録一覧に基づく差分更新へ移す。そのうえで世界小説の内容分類3万→5万→10万以上へ段階的に拡張する。各段階で新規供給数・処理実績・採用率から次の枠を決め、シリーズ分類を単巻作品の分類件数へ足さない。

将来のToC向けには、出典表示・用途条件・履歴管理・応答時間を確認する。独立した推薦品質が未評価であることは明示し、本人の追加採点や有料データ購入を前提にしない。
