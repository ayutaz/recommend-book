# 日本のライトノベルを広く収録する追加計画

更新: 2026-10-25 04:08 JST。[v23](autonomous-next-phase-plan-v23.md)に続く計画。日本のライトノベルを必須対象とし、無料資料と既存Codexのみで進める。購入・外注・本人による入力や評価は求めない。最新の実施結果は[進捗](light-novels-progress-v1.md)へ集約する。

## 到達点と残る問題

シリーズ検索と内容特徴による推薦は利用でき、「魔法科高校の劣等生」の検索、32巻の書誌表示、好きな作品からの推薦は実HTTPとChromeで確認済み。ただし、出版社・レーベル・年代を横断した収録は未完である。変動する収録件数と取得状況は進捗文書の確認時点を参照する。

版の候補数、同じISBNの確認済み版数、シリーズ数、内容分類数を分ける。版を増やすだけではシリーズ検索や推薦に使える作品が同じだけ増えるとは限らないため、収集後の対応づけまで実施する。

## 収録漏れを埋める順序

主要レーベルの取得終端を確認した後、既存の出版社一覧にある未対応シリーズを優先する。続いて旧作・廃刊レーベル、女性向け、Web小説の書籍化、電子専売・合本を確認する。漫画・画集・児童書・ライト文芸・BL/TLなどは資料の種別と根拠を保存し、名称だけで一括採用・排除しない。

旧レーベル補完、歴史候補16名称、主要・Web書籍化等30名称、実在する英字表記13名称は処理状態を確定した。NDL主書誌で実在を確認した徳間・JUMP・女性向け旧作・マッグガーデンの英字表記補完も取得終端に達した。日本語名での検索結果だけを、そのレーベルの全刊行物と見なさない。既存取得に含まれるAnimage、HJ NOVELSや検索結果の部分集合は再取得・再取込みしない。各名称の初回調査と全刊行物の回収を分け、件数が多いという理由だけで無制限の分割取得へ進まない。

アース・スターは192作品参照、TOは1,595商品参照、ガガガは1,310商品URL参照の有限一覧を保存済み。これらは取得枠ごとの異なる単位であり、シリーズ数へ換算しない。TOの禁止された詳細ページは取得せず、許可された一覧の書誌項目を照合に使う。合本・特典付き商品をISBN一致だけで同一商品へまとめない。

アース・スターの192作品ページと明示書籍一覧577参照は取得を終えた。原資料から一覧と著者役割を再現し、NDL主書誌との完全な題名・巻次・著者典拠等の照合を経て対応づける。集英社の明示シリーズも同様に扱い、シリーズ名と各巻の固有題が異なる旧作に対応する。生年付き著者表記の補完は、同一主書誌の明示著作クレジットと唯一の典拠IDが揃う場合に限定し、著者全体の別名や他作品の同一性へ広げない。

## 直近の優先順位

1. KADOKAWA終端13,974版の差分照合は完了し、新たに1,550版を確認した。既存の証拠を保持し、未対応はISBNなし・保存候補なし・複合根拠不足等に分けて不足表へ反映する。同じ全件照合を繰り返さず、新しい情報で解ける残件だけを対象にする。
2. 講談社ラノベ文庫684、ひふみ3レーベル548、オーバーラップ文庫1,019の商品参照を、保存済みNDLへ接続する。保存メタデータの一度の診断では完全題の候補ありはそれぞれ494・104・652参照だった。これらは同定済み版数ではない。まず候補の主書誌・著者役割等を確認し、検索できる書誌との出典付き対応を増やす。
3. 完全題候補がない参照は、書名構成の差と保存書誌不足を分ける。提供元ごとに最大3例の不足を調べ、許可された公式情報のISBN・著者役割などを必要な項目だけ補う。補完の効果を確認してから同じ原因の差分へ広げ、候補なし全件の詳細取得を初手にしない。著者やISBN不明を推測で埋めない。
4. 既存の未対応一覧に沿って主要な不足レーベルを補完する。KADOKAWAの他レーベル、オーバーラップのノベルス等、講談社Kラノベ・f・レジェンド、双葉社、アルファポリス、GC系が残る。各提供元の索引・範囲・終端を確定し、NDLにある候補を先に利用する。双葉社の保存入口はJavaScriptのみで書誌枠が未確立のため、限定した実画面調査から索引を確認する。入口の技術的な未対応を作品不存在として扱わない。
5. 追加された経路の検索・詳細・所属表示を確認し、残る大量未対応と取得枠の不足表を更新する。関連試験、確定実装の両OS CI、文書・PRをまとめて反映する。

シリーズ名、各巻の固有題、別題、著者から検索できる状態を優先する。出版社の「作品グループ」は物語シリーズと区別して表示・集計する。漫画・書影・商品特典・合本を原作小説と一括統合しない。分類未完でも検索と書誌表示を提供し、既存504シリーズの内容特徴を推薦へ利用する。

## 分類精度と利用条件の扱い

自動検証では、証拠との整合性、不正なラベル、矛盾、重複、未知値の扱いを確認する。LLMによる別審査の一致率を、独立した分類精度や信頼度の校正と呼ばない。既存の評価データは同定根拠がある場合だけ接続し、本人の追加採点は求めない。独立した正解集合がない軸の精度、本人向け推薦の改善は未評価として報告する。

書誌・紹介文・画像・本文について、取得、AI入力、画面表示、再配布、商用利用の条件を用途別に保存する。取得できることを全用途の許諾に置き換えない。出版社一覧は発見と照合に使い、紹介文や本文を無条件に分類・再配布しない。原資料・DB・個人履歴はGit対象外とする。

## 無駄な処理を増やさない進め方

独立する収集・照合・実装はSolの担当を分けて並列化し、同じ提供元への取得とDB書込みはそれぞれ一系統にする。提供元のアクセス間隔を守る。KADOKAWAの全件照合は701ページの終端後にまとめ、小さな取得区切りごとに繰り返さない。

内容分類、固定20シリーズの確認、既存世界小説2万分類と履歴の保存確認は、完了済みの証跡を再利用する。新しい変更に関係する試験を行い、全体監査と両OS CIは取得・実装のまとまった区切りに限定する。特徴がない版の詳細表示で、全台帳を走査する類似推薦は実行しない。

## 「ほぼ網羅」の判定と次段階

日本全体の確定した分母はないため、全国の網羅率を作らない。出版社・レーベル・年代・形式別に、一覧総数、取得済み、版照合済み、シリーズ対応済み、未対応、保留、対象外を示す。主要な取得枠や既知の大量未対応が残る間は、ほぼ網羅と判定しない。個別出版社の一覧終端を、日本全体の完了条件へ置き換えない。

ライトノベルの収録と利用が安定した後は、未収録一覧に基づく差分更新へ移す。そのうえで世界小説の内容分類を3万・5万・10万作品以上へ拡張する。ToC化は出典表示、用途条件、履歴管理、応答時間、公開構成を確認して判断し、有料データや外注を前提にしない。
