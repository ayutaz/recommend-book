## 自動評価で確かめる範囲

専門家参照の年齢・職業と、世界6軸72ラベルは別の分類課題として実行・集計する。native A/Bの選択は、固定済みの開発群における年齢・職業の正例検出指標に従う。同じ候補方式を世界ラベルへ用いること自体は全6軸の精度証明にはならないため、世界側の実予測と根拠の意味審査も別に報告する。

100候補のうち、実入力98作品は開発95・評価3作品。100候補に対する2件の入力保留も報告し、98件全体を独立評価群と呼ばない。世界ラベルで専門家参照から比較できる4種の正例は、入力許可後64件で全件が開発群にある。評価群にはその正例がないため、世界ラベルの独立評価点を作らない。

関連度とraw confidenceは保存する。引用の再現、AI間の一致、根拠による意味支持、正解に対する精度、確率校正を区別する。十分な正負例や正解がない軸のprecision/F1・校正済み確率は未評価。追加資料による検証可能範囲の拡大は担当側で行い、成立しなかった範囲を報告に残す。

保存335評点は読み取り専用で使用する。書名類似nDCG@10は0.452627、ID順0.497428、固定乱数0.510569で、改善方式として採用しない。本人の新しい採点を作らず、世界作品との確実な対応だけを比較対象にする。読書状態が不明な候補は「読書状態未確認」と表示する。将来の本人満足度を直接検証する代わりに、既存データで検証できる範囲と未検証範囲を分けて納品する。
