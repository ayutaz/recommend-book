# NDL 26版のオフライン接続可能性調査

2026年10月12日、保存済みのNDL 26版を固定2000作品のWikidata資料と独立した英語古典20作品の資料に照合した。**確実な作品・表現・版の接続は0件、保留3版、情報不足23版**だった。保留14ペアは著者の典拠IDだけが共通し、作品の同一性を裏付けない。DBへの接続・名寄せ・分類入力の変更は行っていない。

これは保存資料に対する機械的な候補調査であり、実人手確認や人手goldではない。取得件数26を、固定作品集合に接続できた版数26として扱わない。

## 入力と保持範囲

| 入力 | 件数 | 用途 |
|---|---:|---|
| `data/ndl-poc/records.jsonl` | 26版 | 元NDL識別子、ISBN、題名、原題注記、典拠、言語、巻次、原XML |
| `data/poc-v1/selected-sources.jsonl` | 2000作品 | 固定されたWD作品集合と保存済み著者資料 |
| `data/prose-poc/source-records.jsonl` | 20作品 | 独立古典の元SourceRecords |
| `data/prose-poc/wikidata-resolution-v1/source-records.jsonl` | 29レコード | 古典を補助するWD作品14・版15の保存資料 |
| `data/prose-poc/wikidata-resolution-v1/identity-map.json` | 20項目 | 保存済みwork/edition関係の照合文脈。既存の保留を確認済みに昇格させない |

入力ごとのSHA256、原データのSHA256、正規化JSONLの行番号・フィールドpointer、原XML/JSONの正確なlocatorを成果物に保存した。WDの保存済みlabels/aliasesも照合し、正規化された英語表示名だけに範囲を限定しなかった。通信・追加LLM要求はともに0。

`data/poc-v1/dataset.sqlite` と `data/poc-frozen-v2/` は書き込まず、対象14ファイルのSHA256を実行前後で比較して一致を確認した。入力5ファイルも実行前後で一致した。既存コードの変更はない。

## 判定方法

- **確実**：作品・表現スコープの明示IDなどで対象を直接裏付けるもの。今回0件。タイトルや著者名が似ていることだけでは確実にしない。
- **保留**：接続の調査に使える共通点があるが、作品・翻訳表現・版の同一性を示す証拠が足りないもの。今回の共通点は著者典拠のみ。
- **情報不足**：固定された保存範囲内に、照合条件を満たす候補を出せないもの。「原典が存在しない」「別作品だ」と断定する状態ではない。

ISBNはチェックディジットを検証し、ISBN-10/13の等価性を正規化して比較した。版スコープのISBNと、WDの作品項目上のISBN claimsを分けて扱い、作品項目にあるISBNをそのまま版IDの確証に転用しない。今回、どちらにもNDL版と共通するISBNはなかった。

原題注記は「原タイトル:」の保存された書誌値を照合した。シリーズ名に続く副題も候補生成で別に検査した。Unicode NFKC・大小文字・空白や句読点の違いは比較用に正規化し、元表記を保持した。曖昧検索は正規化後8文字以上、長さ比0.8以上、SequenceMatcher比率0.86以上を候補条件にしたが、類似だけでは接続を承認しない。今回、完全一致・この条件の類似一致ともに0ペア。

NDLの構造化creatorには訳者・挿絵作者等も含まれ得る。保存済みContributorのroleを無条件に真の著者とみなさず、原XMLの典拠URIとフラットな著者・訳者クレジットを併記した。NDL authorityとWD P349の一致は人物スコープに限る。WD作品のP50も原JSONのlocatorで示すが、同じ人物の別作品をNDL版に接続しない。

## 成果物と再現

保存先は `data/ndl-resolution-review-v1/`。

- `manifest.json`：用途別集計、入力SHA、原物150ファイルのSHA検証、保護対象の前後SHA、通信/LLM/DB更新0。
- `records.jsonl`：NDL全26版の状態・不足・原XMLの書誌根拠。
- `candidate-pairs.jsonl`：保留14ペアの双方の原物・正確locator・欠ける証拠。
- `author-bridges.jsonl`：人物典拠2件。作品・表現・版の接続ではない。
- `analyze.py`：保存資料だけを読む再現用分析。
- `validation.json`：原XMLの816 factと著者関係の原JSON 28 locatorの再解決、ISBN、保護対象の検証結果。

```powershell
uv run python data/ndl-resolution-review-v1/analyze.py
```

原XMLの816個の書誌factについて、保存した名前空間付きXPathを再解決し、値が原物と一致することを検証した。版・作品の接続はDBへ適用せず、将来の追加資料や独立した確認が必要な候補を残した。追加収集をこの調査の完了条件へ黙って置き換えず、今回の固定範囲での不足を結果として報告する。
